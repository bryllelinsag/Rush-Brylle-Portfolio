# Rush Brylle Linsag — Next.js Portfolio

A responsive, motion-led portfolio for Rush Brylle Linsag, a second-year BSIT student with work in graphic design, photo editing, presentations, and web development.

## Routes

- `/` — index page
- `/portfolio` — real school and work-immersion projects
- `/about` — education, skills, and work process
- `/gallery` — project photos and portfolio PDF snapshots

The shared header highlights the active route automatically.

## Run locally

```powershell
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Personalize

Replace the placeholder contact email and social links with Rush's final information. Rush's selected images, rendered PDF pages, and original portfolio PDF are stored in `public/assets/rush/`.
